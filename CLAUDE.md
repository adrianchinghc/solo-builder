# Solo Builder Playbook — Skill Routing

When the user asks anything related to growth, marketing, distribution, launch, pricing, monetization, pivoting, or building a solo business, invoke the relevant `solo-builder:*` skill via the Skill tool BEFORE responding. Do NOT give advice from memory.
